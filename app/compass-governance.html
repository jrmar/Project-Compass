Feature Overview
What the AI Feature Does

The "Explain this Finding" button appears on flagged NIST AI RMF controls in the Dashboard. When clicked, it sends a minimal, structured payload to the Anthropic API (Claude Haiku) and returns a 2–3 sentence plain-language explanation of the gap plus three numbered remediation steps. This feature is local-only; it is not available in the static Vercel deployment unless a Vercel environment variable is configured.

Responsible Use
Responsible AI Use Statement

Project Compass uses AI to augment, not replace, human compliance judgment. The "Explain this Finding" feature is designed to help compliance professionals understand NIST AI RMF control gaps more quickly — it is not a substitute for qualified professional review, legal counsel, or official NIST guidance.

Compass limits AI system scope to the minimum necessary: one feature, advisory outputs only, no automated decisions, no sensitive data transmitted. This reflects our commitment to the same responsible-AI principles we help our users assess in their own tools.

Users who observe unexpected, harmful, or inaccurate AI outputs should report them to the Compass team so they can be investigated and, where appropriate, used to improve the system prompt or disable the feature.

This policy is reviewed quarterly. Changes to the AI integration that alter data flow, model, or vendor require an updated review before deployment.
