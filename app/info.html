About the Project

Understanding Project Compass

A capstone AI governance tool that helps organizations discover, assess, and manage AI tool risk — entirely in the browser, with no data leaving your device.

Workflow
How Project Compass Works

Compass follows a four-step pipeline that takes raw network logs and produces a structured AI risk report aligned to the NIST AI Risk Management Framework.

Step 01
Upload Logs
Provide network or proxy logs (DNS, HTTP, firewall exports) from your organization. Files are read locally in your browser — nothing is uploaded to any server.
Step 02
Detect AI Tools
The log parser matches hostnames against a registry of known AI service domains — OpenAI, Anthropic, Copilot, Hugging Face, and hundreds more — and assigns each a risk tier.
Step 03
Assess Controls
A structured questionnaire maps your existing policies against NIST AI RMF control domains. Responses generate a maturity score and gap analysis across Govern, Map, Measure, and Manage.
Step 04
Generate Report
Three audience-specific views — IT Security, Executive, and Auditor — summarize posture, risk score, maturity rating, and prioritized remediation recommendations.
Log Parser
What the Parser Analyzes

The log parser is the detection engine at the core of Compass. It reads structured log files and matches hostnames and endpoints against a curated registry of known AI service domains, returning enriched tool metadata for each match.

Supported File Formats
Accepts common network log formats exported from proxy servers, next-gen firewalls, and DNS resolvers.
.log .txt .csv .json
Extracted Fields
For each detected AI tool, the parser surfaces the following attributes from the registry lookup.
Tool Name Vendor Category Risk Level Data Class Frequency
Risk Tier Assignment
Each tool is automatically tiered based on data exposure potential, external connectivity, and model type.
Critical High Medium Low
Tool Categories Detected
The registry covers major categories of AI tools in enterprise environments.
LLM / Chat Code Assistant Image Gen Data Pipeline Voice / Speech Search / RAG
AI Registry
The AI Tool Inventory

After detection, every identified tool is added to an AI Inventory — a structured registry your team can review, annotate, and act on. This gives you a living record of AI usage across your organization and the foundation for a governance decision log.

Per-Tool Metadata
Tool name, vendor, category, risk level, data classification, and relative access frequency derived from log volume.
Approval Workflow
Each tool is individually marked Approved, Under Review, or Blocked — tracking governance decisions at the tool level.
Analyst Notes
Expand any inventory row to add free-text notes — document exceptions, risk acceptance rationale, or remediation steps per tool.
Session Storage
Inventory and notes persist within your active browser session. Persistent cross-session storage backed by a database is planned for a future release.
Reporting
Three Audience-Tuned Report Views

The same assessment data is presented three ways so each stakeholder gets exactly the signal they need — without wading through sections written for a different audience.

IT Security View
Full tool list with risk tiers, per-control gap analysis, OWASP LLM mapping, and technical remediation actions sorted by severity.
Executive View
One-page posture summary with a risk score, maturity rating, and three strategic recommendations — designed for a 5-minute briefing.
Auditor View
NIST AI RMF control-by-control coverage table, evidence notes, and a compliance posture declaration formatted for audit documentation.
Data & Privacy
No Data Leaves Your Browser

Project Compass is a client-side application. Your log files, questionnaire answers, and generated reports are processed entirely within your browser tab and are never transmitted to any external server.

Log Files
Parsed in-browser using the File API. The raw file content is never uploaded to any server.
Session Data
Detection results, assessment answers, and inventory state are held in sessionStorage and cleared automatically when you close the tab.
Profile
Org name, your name, and role are saved to localStorage for returning-user convenience. Cleared on Sign Out.
Authentication
Identity via Microsoft Entra External ID using PKCE flow. Tokens stay browser-side; no Compass server holds your credentials.
